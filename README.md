# NEKO JOURNEY｜喵歷險記・手機試玩

這是 NEKO JOURNEY 的**公開手機網頁測試版**（Web Native Alpha），僅包含可在瀏覽器執行的 HTML、CSS 與 JavaScript。

正式 Godot 專案、原始角色美術與私人開發資料不會加入此儲存庫。

遊戲：2D 橫向平台冒險｜手機請橫向使用 Safari 或 Chrome。

正式公開網址由 GitHub Pages 部署完成後提供；在網站實際上線前不推測網址有效。

## 部署

由 `.github/workflows/deploy.yml` 自動發布至 GitHub Pages。若已啟用 GitHub Pages 的 `GitHub Actions` Source，主分支更新後會重新發布手機網頁測試版。
